# Supplementary information: Etymology persists in language user judgements on Hungarian back-neutral nonword stems

## File structure

### script

- gcm.R: GCM code
- fit_gcm.R: fitting GCM, tuning GCM, fitting best model
- load_racz_rebrus.R: load data from Racz & Rebrus CLLT paper
- parse_exp_results.R: parse nonword exp results (not working in anonymous repo)

### dat

- filtered_data_nonword.tsv: filtered exp data, output of parse_exp_results
- unfiltered_data_real_word.tsv: unfiltered exp data, output of parse_exp_results	
- word_distances.tsv.gz: word distances based on natural class-based alignment, see [here](https://escholarship.org/uc/item/914866s3)
- racz_rebrus.tsv: output of load_racz_rebrus
